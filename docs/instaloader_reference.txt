### Only one Post per User

Source: https://instaloader.github.io/codesnippets

This example shows how to download only the most recent post from each user followed by a target profile. It requires the Instaloader library and iterates through followers and their posts.

```python
import instaloader

L = instaloader.Instaloader()

# Login if necessary
# L.login("your_username", "your_password")

profile = instaloader.Profile.from_username(L.context, "instagram")

for follower in profile.get_followers():
    try:
        # Get the most recent post of the follower
        latest_post = next(follower.get_posts())
        print(f"Downloading latest post from {follower.username} ({latest_post.shortcode})")
        L.download_post(latest_post, target=follower.username)
    except StopIteration:
        print(f"No posts found for {follower.username}")
    except Exception as e:
        print(f"Error processing {follower.username}: {e}")
```

### Likes of a Profile / Ghost Followers

Source: https://instaloader.github.io/codesnippets

This example shows how to retrieve the likers of a profile's posts and identify potential 'ghost followers' (users who like posts but don't follow) using the Instaloader Python module. It requires the Instaloader library.

```python
import instaloader

L = instaloader.Instaloader()

# Login if necessary
# L.login("your_username", "your_password")

profile = instaloader.Profile.from_username(L.context, "instagram")

all_followers = set()
for follower in profile.get_followers():
    all_followers.add(follower.username)

likers_of_last_post = set()
for liker in profile.get_posts().__next__().get_likes():
    likers_of_last_post.add(liker.username)

# Find users who liked the last post but do not follow the profile
ghost_followers = likers_of_last_post - all_followers

print(f"Users who liked the last post but do not follow: {ghost_followers}")
```

### Track Deleted Posts

Source: https://instaloader.github.io/codesnippets

This example demonstrates how to track deleted Instagram posts by comparing a downloaded post list with the current posts of a profile. It requires the Instaloader library and saving post metadata.

```python
import instaloader
import json

L = instaloader.Instaloader()

# Login if necessary
# L.login("your_username", "your_password")

profile = instaloader.Profile.from_username(L.context, "instagram")

# Load previously saved post data (if any)
try:
    with open(f"{profile.username}_posts.json", "r") as f:
        saved_posts_data = json.load(f)
        saved_post_ids = set(saved_posts_data.keys())
except FileNotFoundError:
    saved_post_ids = set()

current_post_ids = set()

for post in profile.get_posts():
    current_post_ids.add(post.shortcode)
    # Optionally save current post data if not already saved
    if post.shortcode not in saved_posts_data:
        saved_posts_data[post.shortcode] = {"date": str(post.date)}

# Find deleted posts (posts that were present before but are not now)
deleted_posts = saved_post_ids - current_post_ids

if deleted_posts:
    print(f"Deleted posts: {deleted_posts}")

# Save current post data for future comparison
with open(f"{profile.username}_posts.json", "w") as f:
    json.dump(saved_posts_data, f, indent=2)
```

### Import Firefox Session for Instaloader Login

Source: https://instaloader.github.io/troubleshooting

This script helps bypass Instaloader's login procedure by importing session cookies from Firefox. It requires the 'instaloader' Python package and a Firefox installation with an active Instagram session. The script finds the Firefox cookies.sqlite file, extracts Instagram cookies, and saves them to an Instaloader session file, allowing subsequent Instaloader commands to use the imported session.

```python
from argparse import ArgumentParser
from glob import glob
from os.path import expanduser
from platform import system
from sqlite3 import OperationalError, connect

try:
    from instaloader import ConnectionException, Instaloader
except ModuleNotFoundError:
    raise SystemExit("Instaloader not found.\n  pip install [--user] instaloader")


def get_cookiefile():
    default_cookiefile = {
        "Windows": "~/AppData/Roaming/Mozilla/Firefox/Profiles/*/cookies.sqlite",
        "Darwin": "~/Library/Application Support/Firefox/Profiles/*/cookies.sqlite",
    }.get(system(), "~/.mozilla/firefox/*/cookies.sqlite")
    cookiefiles = glob(expanduser(default_cookiefile))
    if not cookiefiles:
        raise SystemExit("No Firefox cookies.sqlite file found. Use -c COOKIEFILE.")
    return cookiefiles[0]

def import_session(cookiefile, sessionfile):
    print("Using cookies from {}.".format(cookiefile))
    conn = connect(f"file:{cookiefile}?immutable=1", uri=True)
    try:
        cookie_data = conn.execute(
            "SELECT name, value FROM moz_cookies WHERE baseDomain='instagram.com'"
        )
    except OperationalError:
        cookie_data = conn.execute(
            "SELECT name, value FROM moz_cookies WHERE host LIKE '%instagram.com'"
        )
    instaloader = Instaloader(max_connection_attempts=1)
    instaloader.context._session.cookies.update(cookie_data)
    username = instaloader.test_login()
    if not username:
        raise SystemExit("Not logged in. Are you logged in successfully in Firefox?")
    print("Imported session cookie for {}.".format(username))
    instaloader.context.username = username
    instaloader.save_session_to_file(sessionfile)


if __name__ == "__main__":
    p = ArgumentParser()
    p.add_argument("-c", "--cookiefile")
    p.add_argument("-f", "--sessionfile")
    args = p.parse_args()
    try:
        import_session(args.cookiefile or get_cookiefile(), args.sessionfile)
    except (ConnectionException, OperationalError) as e:
        raise SystemExit("Cookie import failed: {}".format(e))

```

### Instaloader Path Sanitization and Resume Functionality

Source: https://instaloader.github.io/cli-options

Options for ensuring valid file paths and managing interrupted downloads. `--sanitize-paths` makes filenames compatible with different operating systems, while `--resume-prefix` and `--no-resume` control the mechanism for resuming aborted download sessions.

```APIDOC
--sanitize-paths
    Force sanitization of paths so that the resulting file and directory names are valid on both Windows and Unix.
    Added in version 4.9.

--resume-prefix prefix
    For many targets, Instaloader is capable of resuming a previously-aborted download loop. To do so, it creates a JSON file within the target directory when interrupted. This option controls the prefix for filenames that are used to save the information to resume an interrupted download. The default prefix is `iterator`.
    Resuming an interrupted download is supported for the following targets:
      * Profile posts,
      * Profile IGTV posts (--igtv),
      * Profile tagged posts (--tagged),
      * Saved posts (:saved),
      * Hashtags.
    This feature is enabled by default for targets where it is supported; --resume-prefix only changes the name of the iterator files.
    To turn this feature off, use --no-resume.
    JSON files with resume information are always compressed, regardless of --no-compress-json.
    Added in version 4.5.

--no-resume
    Do not resume a previously-aborted download iteration, and do not save such information when interrupted.
    Added in version 4.5.
```

### Instaloader Instantiation and Offline Post Comparison

Source: https://instaloader.github.io/codesnippets

Demonstrates how to instantiate Instaloader, load a session, and compare offline posts (from JSON files) with online posts for a given profile. It identifies posts that are new or have been deleted.

```python
from instaloader import Instaloader, Profile
from glob import glob
from os import chdir
from sys import argv

# Instaloader instantiation - you may pass additional arguments to the constructor here
L = Instaloader()

# If desired, load session previously saved with `instaloader -l USERNAME`:
#L.load_session_from_file(USERNAME)

try:
    TARGET = argv[1]
except IndexError:
    raise SystemExit("Pass profile name as argument!")

# Obtain set of posts that are on hard disk
chdir(TARGET)
offline_posts = set(filter(lambda s: isinstance(s, Post),
                           (load_structure_from_file(L.context, file)
                            for file in (glob('*.json.xz') + glob('*.json')))))

# Obtain set of posts that are currently online
post_iterator = Profile.from_username(L.context, TARGET).get_posts()
online_posts = set(post_iterator)

if online_posts - offline_posts:
    print("Not yet downloaded posts:")
    print(" ".join(str(p) for p in (online_posts - offline_posts)))

if offline_posts - online_posts:
    print("Deleted posts:")
    print(" ".join(str(p) for p in (offline_posts - online_posts)))

```

### Instaloader Filename and Directory Patterns

Source: https://instaloader.github.io/basic-usage

Configures how Instaloader names directories and files for downloaded posts and stories. Supports various tokens for customization.

```APIDOC
Instaloader Filename Specification:

--dirname-pattern={target}
  - Configures the directory name for each target. Default is '{target}'.
  - Tokens:
    - {target}: Target name (as given in Instaloader command line).
    - {profile}: Owner of the Post / StoryItem / ProfilePic. For hashtag profile pics and highlight covers, equivalent to {target}.

--filename-pattern={date_utc}_UTC
  - Configures the path of the post and story’s files relative to the target directory.
  - Default is '{date_utc}_UTC'.
  - Tokens:
    - {target}: Target name.
    - {profile}: Owner of the Post / StoryItem / ProfilePic.
    - {owner_id}: Unique integer ID of owner profile.
    - {shortcode}: Shortcode (identifier string). Not available for --title-pattern.
    - {mediaid}: Integer representation of shortcode. Not available for --title-pattern.
    - {filename}: Instagram’s internal filename.
    - {date_utc}: Creation time in UTC timezone. Supports strftime()-style formatting.
    - {typename}: Type of media being saved (e.g., GraphImage, profile_pic).

--title-pattern={date_utc}_UTC_{typename}
  - Configures filenames for profile pics, hashtag profile pics, and highlight covers.
  - Default depends on --dirname-pattern.
  - Tokens are similar to --filename-pattern, with some exclusions for {shortcode} and {mediaid}.

Examples:
  - Encode poster's profile name: --dirname-pattern={profile}
  - Store posts in PROFILE/YEAR/SHORTCODE.jpg: --dirname-pattern={profile}/{date:%Y}/ --filename-pattern={shortcode}
```

### Instaloader Resumable Iteration Context Manager

Source: https://instaloader.github.io/module/nodeiterator

Provides a context manager for handling resumable iterations, allowing progress to be saved and loaded across interruptions (like KeyboardInterrupt or AbortDownloadException). It manages the loading and saving of iteration state.

```APIDOC
instaloader.resumable_iteration(_context :[InstaloaderContext](https://instaloader.github.io/module/instaloadercontext.html#instaloader.InstaloaderContext)_, _iterator :[Iterable](https://docs.python.org/3/library/typing.html#typing.Iterable)_, _load :[Callable](https://docs.python.org/3/library/typing.html#typing.Callable)[[[InstaloaderContext](https://instaloader.github.io/module/instaloadercontext.html#instaloader.InstaloaderContext),[str](https://docs.python.org/3/library/stdtypes.html#str)],[Any](https://docs.python.org/3/library/typing.html#typing.Any)]_, _save :[Callable](https://docs.python.org/3/library/typing.html#typing.Callable)[[[FrozenNodeIterator](https://instaloader.github.io/module/nodeiterator.html#instaloader.FrozenNodeIterator),[str](https://docs.python.org/3/library/stdtypes.html#str)],[None](https://docs.python.org/3/library/constants.html#None)]_, _format_path :[Callable](https://docs.python.org/3/library/typing.html#typing.Callable)[[[str](https://docs.python.org/3/library/stdtypes.html#str)],[str](https://docs.python.org/3/library/stdtypes.html#str)]_, _check_bbd :[bool](https://docs.python.org/3/library/functions.html#bool)=True_, _enabled :[bool](https://docs.python.org/3/library/functions.html#bool)=True_) → [Iterator](https://docs.python.org/3/library/typing.html#typing.Iterator)[[Tuple](https://docs.python.org/3/library/typing.html#typing.Tuple)[[bool](https://docs.python.org/3/library/functions.html#bool),[int](https://docs.python.org/3/library/functions.html#int)]][¶](https://instaloader.github.io/module/nodeiterator.html#instaloader.resumable_iteration) 
    
High-level context manager to handle a resumable iteration that can be interrupted with a [`KeyboardInterrupt`](https://docs.python.org/3/library/exceptions.html#KeyboardInterrupt) or an [`AbortDownloadException`](https://instaloader.github.io/module/exceptions.html#instaloader.AbortDownloadException). 
It can be used as follows to automatically load a previously-saved state into the iterator, save the iterator’s state when interrupted, and delete the resume file upon completion:
```python
post_iterator = profile.get_posts()
with resumable_iteration(
        context=L.context,
        iterator=post_iterator,
        load=lambda _, path: FrozenNodeIterator(**json.load(open(path))),
        save=lambda fni, path: json.dump(fni._asdict(), open(path, 'w')),
        format_path=lambda magic: "resume_info_{}.json".format(magic)
) as (is_resuming, start_index):
    for post in post_iterator:
        do_something_with(post)

```

It yields a tuple (is_resuming, start_index). 
When the passed iterator is not a [`NodeIterator`](https://instaloader.github.io/module/nodeiterator.html#instaloader.NodeIterator), it behaves as if `resumable_iteration` was not used, just executing the inner body. 

Parameters: 
    
  * **context** – The [`InstaloaderContext`](https://instaloader.github.io/module/instaloadercontext.html#instaloader.InstaloaderContext). 
  * **iterator** – The fresh [`NodeIterator`](https://instaloader.github.io/module/nodeiterator.html#instaloader.NodeIterator). 
  * **load** – Loads a FrozenNodeIterator from given path. The object is ignored if it has a different type. 
  * **save** – Saves the given FrozenNodeIterator to the given path. 
  * **format_path** – Returns the path to the resume file for the given magic. 
  * **check_bbd** – Whether to check the best before date and reject an expired FrozenNodeIterator. 
  * **enabled** – Set to False to disable all functionality and simply execute the inner body. 


Changed in version 4.7: Also interrupt on [`AbortDownloadException`](https://instaloader.github.io/module/exceptions.html#instaloader.AbortDownloadException).
```

### Instaloader CLI Options for Post Download Control

Source: https://instaloader.github.io/cli-options

This entry consolidates various command-line options for Instaloader that control which posts are downloaded. It includes options for optimizing update processes and filtering content based on specific criteria.

```APIDOC
--fast-update, -F
    Stops downloading when the first already-downloaded picture is encountered. Recommended for updating personal Instagram archives.

--latest-stamps [STAMPSFILE]
    Similar to --fast-update, but uses a timestamp file to track the last download time for each profile. Only fetches media newer than the last download. Allows updating archives while emptying target directories. Works for profile posts, stories, IGTV, and tagged posts. Default location: ~/.config/instaloader/latest-stamps.ini. Added in version 4.8.

--storyitem-filter filter
    Downloads only story items for which the given Python expression evaluates to True. Variables in the expression correspond to instaloader.StoryItem attributes. See Filter Posts for more examples.

--count COUNT, -c
    Limits the number of posts downloaded. Applies to #hashtag, %location_id, :feed, and :saved targets.
```

### Instaloader Connection and Request Settings

Source: https://instaloader.github.io/cli-options

Configure network-related behavior for Instaloader. This includes setting the User-Agent string, defining the maximum number of connection attempts, specifying request timeouts, and determining which HTTP status codes should cause an immediate abort.

```APIDOC
--user-agent USER_AGENT
    User Agent to use for HTTP requests. Per default, Instaloader pretends being Chrome/127 on Linux.

--max-connection-attempts N
    Maximum number of connection attempts until a request is aborted. Defaults to `3`. If a connection fails, it can be manually skipped by hitting `Control`-`c`. Set this to `0` to retry infinitely.

--request-timeout N
    Seconds to wait before timing out a connection request. Defaults to 300.
    Added in version 4.3.
    Changed in version 4.6: Enabled this option by default with a timeout of 300 seconds.

--abort-on STATUS_CODE_LIST
    Comma-separated list of HTTP status codes that cause Instaloader to abort, bypassing all retry logic.
    For example, with --abort-on=302,400,429, Instaloader will stop if a request is responded with a 302 redirect, a Bad Request error, or a Too Many Requests error.
    Added in version 4.7.
```

### Download Top X% Liked Posts of a User

Source: https://instaloader.github.io/codesnippets

Downloads a specified percentage of a user's posts, prioritizing those with the most likes and comments. It sorts all posts by their engagement metrics and then selects the top posts based on the given percentage.

```python
from itertools import islice
from math import ceil

from instaloader import Instaloader, Profile

PROFILE = ...        # profile to download from
X_percentage = 10    # percentage of posts that should be downloaded

L = Instaloader()

profile = Profile.from_username(L.context, PROFILE)
posts_sorted_by_likes = sorted(profile.get_posts(),
                               key=lambda p: p.likes + p.comments,
                               reverse=True)

for post in islice(posts_sorted_by_likes, ceil(profile.mediacount * X_percentage / 100)):
    L.download_post(post, PROFILE)

```

### Download Instagram Posts in a Specific Period (Chronological)

Downloads Instagram posts within a specified date range using `itertools.dropwhile` and `itertools.takewhile`. This method assumes posts are returned in exact chronological order. It requires the `instaloader` and `datetime` libraries.

```Python
from datetime import datetime
from itertools import dropwhile, takewhile

import instaloader

L = instaloader.Instaloader()

posts = instaloader.Profile.from_username(L.context, "instagram").get_posts()

SINCE = datetime(2015, 5, 1)
UNTIL = datetime(2015, 3, 1)

for post in takewhile(lambda p: p.date > UNTIL, dropwhile(lambda p: p.date > SINCE, posts)):

    L.download_post(post, "instagram")

### Download Instagram Posts in a Specific Period (Near Chronological)

Source: https://instaloader.github.io/codesnippets

Downloads Instagram posts within a specified date range, handling near-chronological order where older posts might be interspersed. It uses a counter `k` to manage deviations from strict chronological order. Requires `instaloader` and `datetime`.

```Python
from datetime import datetime
import instaloader

L = instaloader.Instaloader()

posts = instaloader.Hashtag.from_name(L.context, "urbanphotography").get_posts()

SINCE = datetime(2020, 5, 10)  # further from today, inclusive
UNTIL = datetime(2020, 5, 11)  # closer to today, not inclusive

k = 0  # initiate k

for post in posts:
    postdate = post.date

    if postdate > UNTIL:
        continue
    elif postdate <= SINCE:
        k += 1
        if k == 50:
            break
        else:
            continue
    else:
        L.download_post(post, "#urbanphotography")
        k = 0  # set k to 0

```

### Identify Ghost Followers (Inactive Followers)

Source: https://instaloader.github.io/codesnippets

Finds Instagram followers who have not liked any of the user's posts. It loads a session, fetches all posts, collects likes from each post, retrieves followers, and then calculates the difference to find inactive users. Requires `instaloader`.

```Python
import instaloader

L = instaloader.Instaloader()

USER = "your_account"
PROFILE = USER

# Load session previously saved with `instaloader -l USERNAME`:
L.load_session_from_file(USER)

profile = instaloader.Profile.from_username(L.context, PROFILE)

likes = set()
print("Fetching likes of all posts of profile {}".format(profile.username))
for post in profile.get_posts():
    print(post)
    likes = likes | set(post.get_likes())

print("Fetching followers of profile {}".format(profile.username))
followers = set(profile.get_followers())

ghosts = followers - likes

print("Storing ghosts into file.")
with open("inactive-users.txt", 'w') as f:
    for ghost in ghosts:
        print(ghost.username, file=f)

```
